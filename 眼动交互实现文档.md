# PICO 眼动交互（Eye Gaze Interaction）实现文档

> 适用平台：PICO Neo3 Pro Eye / PICO 4 Pro / PICO 4 Enterprise（仅这几款带眼动硬件）
> 依赖：Unity + **PICO Unity Integration SDK 3.4.0**（本项目用的是 PXR 体系，非 OpenXR 分支）
> 本文档基于 `Virtual Exhibition Guide` 项目实测代码 + SDK 源码 `PXR_EyeTracking.cs` 整理，照做即可在新项目复刻"注视高亮 + 停留触发面板"的眼动交互。

---

## 一、交互效果与整体流程

效果：用眼睛注视场景里的展品 → 展品**高亮 + 微放大** → 注视停留满 N 秒（dwell，默认 1.5s）→ 触发选中 → **弹出信息面板**（标题/描述/图片/视频/音效）。注视一个标着"关闭"的物体同样停留即可关闭面板。

数据流（一帧内）：

```
眼动硬件 → PXR_EyeTracking 取原始数据(相机坐标系)
        → 坐标矩阵转换为世界空间 Ray
        → Physics.Raycast 命中 GazeInteractable
        → 高亮 + dwell 计时
        → 计时满 → Select() → 面板控制器显示/隐藏
```

**架构关键点：用接口 `IGazeInputSource` 把"眼动数据来源"和"选择逻辑"解耦。** 这样编辑器里可以用鼠标/摄像机朝向模拟，真机上才走 PICO 眼动 API，业务逻辑（射线检测、停留、面板）完全不用改。新项目里只要复用这一套接口就能即插即用。

## 二、前置条件（务必先配好，否则真机取不到数据）

### 1. 安装 PICO SDK
通过 Package Manager 引入 PICO Unity Integration SDK（本项目用 3.4.0）。`Packages/manifest.json` 里形如：
```json
"com.unity.xr.picoxr": "file:.../PICO Unity Integration SDK-3.4.0-..."
```

### 2. 开启眼动开关（最关键，漏掉则 100% 取不到数据）
菜单 **PICO → PXR_ProjectSetting**，勾选：
- ✅ **Eye Tracking**
- ✅ **Eye Tracking Calibration**

勾选后会写入 `Assets/Resources/PXR_ProjectSetting.asset`，本项目实测值：
```yaml
eyeTracking: 1
eyetrackingCalibration: 1
```
> 代码里 `PXR_Manager.Instance.eyeTracking` 为 false 时，`PXR_EyeTracking` 的所有取数方法都直接返回 false——所以这个开关是总闸。

### 3. Android 权限（SDK 自动注入，一般不用手动加）
打包时 SDK 的 `PXR_BuildProcessor` 检测到 eyeTracking 开启后，会自动往 `AndroidManifest.xml` 写入：
```xml
<uses-permission android:name="com.picovr.permission.EYE_TRACKING" />
```
> 出处：SDK `Editor/PXR_BuildProcessor.cs`。如果你用自定义 manifest 覆盖了 SDK 的，需手动补这一行。

### 4. Player / XR 设置
- Build Target：**Android**
- XR Plug-in Management 启用 **PICO**
- 场景里要有 PICO 的 **XR Origin (VR)**（含 PXR_Manager / Main Camera）

## 三、核心 PICO 眼动 API 速查（`Unity.XR.PXR.PXR_EyeTracking`）

全部为静态方法，返回 `bool`（true=成功取到，false=失败/未开启/设备无效）。**取数前内部都会检查 `PXR_Manager.Instance.eyeTracking` 和眼动设备有效性。**

| 方法 | 作用 | out 参数含义 |
|---|---|---|
| `GetHeadPosMatrix(out Matrix4x4 matrix)` | 头部位姿矩阵（相对追踪空间） | 头的 TRS 矩阵，用于把眼动数据从相机坐标系转到世界 |
| `GetCombineEyeGazePoint(out Vector3 point)` | 双眼合并注视**起点**（相机坐标系，单位米） | 注视射线原点 |
| `GetCombineEyeGazeVector(out Vector3 vector)` | 双眼合并注视**方向**（相机坐标系） | 注视射线方向（需归一化） |
| `GetLeftEyeGazeOpenness(out float openness)` | 左眼睁开度 | 0.0=全闭, 1.0=全睁（可做眨眼检测） |
| `GetRightEyeGazeOpenness(out float openness)` | 右眼睁开度 | 同上 |
| `GetCombinedEyePoseStatus(out uint status)` | 合并眼数据是否可用 | 0=不可用, 1=可用 |
| `GetLeftEyePoseStatus(out uint status)` | 左眼各项数据有效位 | 位掩码，见下方 EyePoseStatus |
| `GetRightEyePoseStatus(out uint status)` | 右眼各项数据有效位 | 同上 |
| `GetLeftEyePositionGuide(out Vector3)` / `GetRightEyePositionGuide` | 眼睛在传感器内的位置（戴正引导） | (0,0)右上 ~ (1,1)左下 |
| `GetFoveatedGazeDirection(out Vector3)` | 注视点渲染中心方向 | 用于 FFR |
| `GetFoveatedGazeTrackingState(out uint state)` | 注视渲染数据是否可用 | 0/1 |

**EyePoseStatus 位掩码**（配合 `GetXxxEyePoseStatus` 判断某项数据是否有效）：
```
GazePointValid              = 1 << 0
GazeVectorValid             = 1 << 1
EyeOpennessValid            = 1 << 2
EyePupilDilationValid       = 1 << 3
EyePositionGuideValid       = 1 << 4
EyePupilPositionValid       = 1 << 5
EyeConvergenceDistanceValid = 1 << 6
EyeGazePointValid           = 1 << 7
EyeGazeVectorValid          = 1 << 8
PupilDistanceValid          = 1 << 9
ConvergenceDistanceValid    = 1 << 10
PupilDiameterValid          = 1 << 11
```

> 做"注视交互"只需要 3 个方法：`GetHeadPosMatrix` + `GetCombineEyeGazePoint` + `GetCombineEyeGazeVector`。其余是进阶（眨眼、瞳孔、戴正引导）。

## 四、坐标转换：把眼动数据变成世界空间射线（接口匹配的核心）

PICO 返回的注视起点/方向是**相机（HMD）坐标系**下的，要做 `Physics.Raycast` 必须转到**世界坐标系**。转换需要两段矩阵相乘：

```
世界射线 = XROrigin的localToWorld矩阵 × 头部位姿矩阵 × 眼动原始数据
```

为什么是两段：
1. `headPoseMatrix`：把眼动数据（相对相机/头）→ 追踪空间（相对 XR Origin）
2. `originPoseMatrix`（= `xrOriginTransform.localToWorldMatrix`）：把追踪空间 → Unity 世界空间。**因为你的 XR Origin 在场景里可能被移动/旋转/缩放过，必须乘它的世界矩阵，否则人走动后射线就错位。**

官方/本项目实测转换代码（`XREyeGazeInputSource.TryGetGazeRay` 真机分支）：

```csharp
Matrix4x4 headPoseMatrix;
Vector3 combineEyeGazeVector;   // 方向，相机系
Vector3 combineEyeGazeOrigin;   // 起点，相机系

PXR_EyeTracking.GetHeadPosMatrix(out headPoseMatrix);
PXR_EyeTracking.GetCombineEyeGazeVector(out combineEyeGazeVector);
PXR_EyeTracking.GetCombineEyeGazePoint(out combineEyeGazeOrigin);

// XR Origin 的世界矩阵
Matrix4x4 originPoseMatrix = xrOriginTransform != null
    ? xrOriginTransform.localToWorldMatrix
    : Matrix4x4.identity;

// 起点：用 MultiplyPoint（含平移）
Vector3 originWorld = originPoseMatrix.MultiplyPoint(
                          headPoseMatrix.MultiplyPoint(combineEyeGazeOrigin));
// 方向：用 MultiplyVector（不含平移，只旋转/缩放）
Vector3 vectorWorld = originPoseMatrix.MultiplyVector(
                          headPoseMatrix.MultiplyVector(combineEyeGazeVector));

if (vectorWorld.sqrMagnitude > 0.001f)   // 数据有效才用
{
    gazeRay = new Ray(originWorld, vectorWorld.normalized);
    return true;
}
```

> ⚠️ 易错点：
> - 起点用 `MultiplyPoint`，方向用 `MultiplyVector`，**不能混用**（方向若用 MultiplyPoint 会被平移污染）。
> - `xrOriginTransform` 必须拖你的 **XR Origin (VR) 最外层父物体**，不是 Main Camera。
> - 方向最后要 `.normalized`。

## 五、脚本架构（5 个脚本，可直接复制到新项目）

| 脚本 | 职责 | 挂载位置 |
|---|---|---|
| `IGazeInputSource.cs` | 接口：抽象"眼动数据源" | —（接口） |
| `XREyeGazeInputSource.cs` | 实现接口：真机走 PICO API，编辑器用鼠标/相机模拟 | 一个空物体（如 GazeManager） |
| `GazeSelectionController.cs` | 核心：取射线→Raycast→高亮→dwell 停留→触发选中 | 同上 GazeManager |
| `GazeInteractable.cs` | 挂在每个可注视物体上：高亮/缩放/事件、标记类型与数据 | 每个展品 |
| `ExhibitionInfoPanelController.cs` | 信息面板显隐与内容填充（文/图/视频/音） | 面板根物体 |
| `ExhibitInfo.cs` | 纯数据类：一个展品的标题/描述/图/视频/音 | —（[Serializable] 字段） |

### 5.1 IGazeInputSource.cs —— 解耦接口
```csharp
using UnityEngine;

public interface IGazeInputSource
{
    bool IsEyeTrackingSupported { get; }
    bool IsEyeTrackingActive { get; }
    void StartTracking();
    void StopTracking();
    bool TryGetGazeRay(out Ray gazeRay);   // 拿到世界空间注视射线
}
```

### 5.2 XREyeGazeInputSource.cs —— 真机/编辑器双模数据源
```csharp
using UnityEngine;
using Unity.XR.PXR; // PICO 官方命名空间

public class XREyeGazeInputSource : MonoBehaviour, IGazeInputSource
{
    [Header("Fallback & Editor Simulation")]
    [SerializeField] private Camera fallbackCamera;
    [SerializeField] private bool simulateInEditor = true;
    [SerializeField] private bool useMousePointInEditor = true;

    [Header("XR Origin (必须赋值，用于坐标矩阵转换)")]
    [Tooltip("请将你的 XR Origin (VR) 最外层父物体拖到这里")]
    [SerializeField] private Transform xrOriginTransform;

    private bool trackingStarted = false;

    public bool IsEyeTrackingSupported => true;
    public bool IsEyeTrackingActive => trackingStarted;

    private void Awake()
    {
        if (fallbackCamera == null) fallbackCamera = Camera.main;

        // 自动寻找 XR Origin（相机的父物体）
        if (xrOriginTransform == null && fallbackCamera != null)
        {
            xrOriginTransform = fallbackCamera.transform.parent != null
                ? fallbackCamera.transform.parent
                : fallbackCamera.transform;
        }
    }

    public void StartTracking() => trackingStarted = true;
    public void StopTracking()  => trackingStarted = false;

    public bool TryGetGazeRay(out Ray gazeRay)
    {
        // —— 编辑器模拟：鼠标位置 or 相机正前方 ——
        if (Application.isEditor && simulateInEditor)
        {
            if (fallbackCamera != null && useMousePointInEditor)
            {
                gazeRay = fallbackCamera.ScreenPointToRay(Input.mousePosition);
                return true;
            }
            if (fallbackCamera != null)
            {
                gazeRay = new Ray(fallbackCamera.transform.position,
                                  fallbackCamera.transform.forward);
                return true;
            }
            gazeRay = default;
            return false;
        }

        if (!trackingStarted) { gazeRay = default; return false; }

        // —— 真机：PICO 眼动 API + 坐标转换（仅非编辑器编译） ——
        #if !UNITY_EDITOR
        Matrix4x4 headPoseMatrix;
        Vector3 combineEyeGazeVector;
        Vector3 combineEyeGazeOrigin;

        PXR_EyeTracking.GetHeadPosMatrix(out headPoseMatrix);
        PXR_EyeTracking.GetCombineEyeGazeVector(out combineEyeGazeVector);
        PXR_EyeTracking.GetCombineEyeGazePoint(out combineEyeGazeOrigin);

        Matrix4x4 originPoseMatrix = xrOriginTransform != null
            ? xrOriginTransform.localToWorldMatrix : Matrix4x4.identity;

        Vector3 originWorld = originPoseMatrix.MultiplyPoint(
                                  headPoseMatrix.MultiplyPoint(combineEyeGazeOrigin));
        Vector3 vectorWorld = originPoseMatrix.MultiplyVector(
                                  headPoseMatrix.MultiplyVector(combineEyeGazeVector));

        if (vectorWorld.sqrMagnitude > 0.001f)
        {
            gazeRay = new Ray(originWorld, vectorWorld.normalized);
            return true;
        }
        #endif

        // —— 兜底：相机正前方 ——
        if (fallbackCamera != null)
        {
            gazeRay = new Ray(fallbackCamera.transform.position,
                              fallbackCamera.transform.forward);
            return true;
        }
        gazeRay = default;
        return false;
    }
}
```
> `#if !UNITY_EDITOR` 包住真机分支，是为了让没装 PICO 真机库的编辑器也能编译/运行（编辑器走鼠标模拟）。新项目保持这个写法。

### 5.3 GazeSelectionController.cs —— 注视选择核心
```csharp
using UnityEngine;
using UnityEngine.Events;
using UnityEngine.UI;

public class GazeSelectionController : MonoBehaviour
{
    [Header("Input")]
    [SerializeField] private MonoBehaviour gazeInputSourceBehaviour; // 拖 XREyeGazeInputSource

    [Header("Selection")]
    [SerializeField] private float maxRayDistance = 30f;
    [SerializeField] private float dwellDuration = 1.5f;             // 停留触发时长
    [SerializeField] private LayerMask interactableLayerMask = ~0;

    [Header("UI")]
    [SerializeField] private Image gazeProgressImage;               // 圆环进度（Filled）
    [SerializeField] private ExhibitionInfoPanelController infoPanelController;

    [Header("Events")]
    [SerializeField] private UnityEvent<float> onProgressChanged;
    [SerializeField] private UnityEvent<GazeInteractable> onTargetSelected;

    private IGazeInputSource gazeInputSource;
    private GazeInteractable currentTarget;
    private float dwellTimer;
    private bool selectedCurrentTarget;

    private void Awake()
    {
        gazeInputSource = gazeInputSourceBehaviour as IGazeInputSource;
        if (gazeInputSource == null) gazeInputSource = GetComponent<IGazeInputSource>();
        SetProgress(0f);
    }

    private void OnEnable()  => gazeInputSource?.StartTracking();
    private void OnDisable() { gazeInputSource?.StopTracking(); ClearCurrentTarget(); }

    private void Update()
    {
        if (gazeInputSource == null || !gazeInputSource.TryGetGazeRay(out Ray gazeRay))
        {
            ClearCurrentTarget();
            return;
        }

        if (Physics.Raycast(gazeRay, out RaycastHit hit, maxRayDistance,
                            interactableLayerMask, QueryTriggerInteraction.Collide))
        {
            // GetComponentInParent：碰撞体可以在子物体上
            GazeInteractable target = hit.collider.GetComponentInParent<GazeInteractable>();
            if (target != null) { HandleTarget(target); return; }
        }
        ClearCurrentTarget();
    }

    private void HandleTarget(GazeInteractable target)
    {
        if (target != currentTarget) SwitchTarget(target);
        if (selectedCurrentTarget) { SetProgress(1f); return; } // 已选中，不重复触发

        dwellTimer += Time.deltaTime;
        SetProgress(Mathf.Clamp01(dwellTimer / dwellDuration));
        if (dwellTimer >= dwellDuration) SelectCurrentTarget();
    }

    private void SwitchTarget(GazeInteractable newTarget)
    {
        if (currentTarget != null) currentTarget.SetFocused(false);
        currentTarget = newTarget;
        dwellTimer = 0f; selectedCurrentTarget = false; SetProgress(0f);
        if (currentTarget != null) currentTarget.SetFocused(true);
    }

    private void SelectCurrentTarget()
    {
        if (currentTarget == null) return;
        selectedCurrentTarget = true;
        currentTarget.Select();
        onTargetSelected?.Invoke(currentTarget);

        if (infoPanelController != null)
        {
            if (currentTarget.Type == GazeInteractable.InteractionType.CloseInfoPanel)
            {
                infoPanelController.HidePanel();
                ResetSelectionStateForCurrentTarget();
                return;
            }
            infoPanelController.ShowExhibit(currentTarget.Info);
        }
    }

    private void ClearCurrentTarget()
    {
        if (currentTarget != null) { currentTarget.SetFocused(false); currentTarget = null; }
        dwellTimer = 0f; selectedCurrentTarget = false; SetProgress(0f);
    }

    private void SetProgress(float progress)
    {
        if (gazeProgressImage != null)
        {
            gazeProgressImage.fillAmount = progress;
            gazeProgressImage.enabled = progress > 0f && progress < 1f;
        }
        onProgressChanged?.Invoke(progress);
    }

    private void ResetSelectionStateForCurrentTarget()
    {
        dwellTimer = 0f; selectedCurrentTarget = false; SetProgress(0f);
    }
}
```

### 5.4 GazeInteractable.cs —— 可注视物体（高亮/缩放/数据）
```csharp
using UnityEngine;
using UnityEngine.Events;

public class GazeInteractable : MonoBehaviour
{
    public enum InteractionType { OpenExhibit, CloseInfoPanel }

    [Header("Interaction")]
    [SerializeField] private InteractionType interactionType = InteractionType.OpenExhibit;
    [SerializeField] private ExhibitInfo exhibitInfo;

    [Header("Visual Feedback")]
    [SerializeField] private Transform scaleTarget;
    [SerializeField] private float focusScaleMultiplier = 1.08f;
    [SerializeField] private Renderer[] highlightRenderers;
    [SerializeField] private Color normalColor = Color.white;
    [SerializeField] private Color focusColor = new Color(1f, 0.9f, 0.2f, 1f);

    [Header("Events")]
    [SerializeField] private UnityEvent onFocusEnter;
    [SerializeField] private UnityEvent onFocusExit;
    [SerializeField] private UnityEvent onSelected;

    // URP 用 _BaseColor，内置管线用 _Color；两个都试
    private static readonly int BaseColorId = Shader.PropertyToID("_BaseColor");
    private static readonly int ColorId = Shader.PropertyToID("_Color");

    private bool hasFocus;
    private Vector3 initialScale;
    private MaterialPropertyBlock propertyBlock;

    public InteractionType Type => interactionType;
    public ExhibitInfo Info => exhibitInfo;

    private void Awake()
    {
        if (scaleTarget == null) scaleTarget = transform;
        initialScale = scaleTarget.localScale;
        propertyBlock = new MaterialPropertyBlock();
        ApplyHighlightColor(normalColor);
    }

    public void SetFocused(bool focused)
    {
        if (hasFocus == focused) return;
        hasFocus = focused;
        scaleTarget.localScale = focused ? initialScale * focusScaleMultiplier : initialScale;
        ApplyHighlightColor(focused ? focusColor : normalColor);
        if (focused) onFocusEnter?.Invoke(); else onFocusExit?.Invoke();
    }

    public void Select() => onSelected?.Invoke();

    private void ApplyHighlightColor(Color color)
    {
        if (highlightRenderers == null || highlightRenderers.Length == 0) return;
        for (int i = 0; i < highlightRenderers.Length; i++)
        {
            Renderer r = highlightRenderers[i];
            if (r == null) continue;
            r.GetPropertyBlock(propertyBlock);            // 用 MaterialPropertyBlock 不会改共享材质
            Material m = r.sharedMaterial;
            if (m != null && m.HasProperty(BaseColorId)) propertyBlock.SetColor(BaseColorId, color);
            else                                          propertyBlock.SetColor(ColorId, color);
            r.SetPropertyBlock(propertyBlock);
        }
    }
}
```
> 高亮用 `MaterialPropertyBlock`：只改这一个 Renderer 的显示颜色，不会污染共享材质、不产生材质实例，性能好。

### 5.6 ExhibitionInfoPanelController.cs —— 信息面板
```csharp
using TMPro;
using UnityEngine;
using UnityEngine.UI;
using UnityEngine.Video;

public class ExhibitionInfoPanelController : MonoBehaviour
{
    [Header("Panel Root")]
    [SerializeField] private GameObject panelRoot;

    [Header("Text")]
    [SerializeField] private TMP_Text titleText;
    [SerializeField] private TMP_Text descriptionText;

    [Header("Image")]
    [SerializeField] private Image imageView;

    [Header("Video")]
    [SerializeField] private RawImage videoView;
    [SerializeField] private VideoPlayer videoPlayer;

    [Header("Audio")]
    [SerializeField] private AudioSource audioSource;
    [SerializeField] private AudioClip defaultSelectionAudio;

    public bool IsVisible => panelRoot != null && panelRoot.activeSelf;

    private void Awake()
    {
        if (panelRoot != null) panelRoot.SetActive(false);
        if (videoPlayer != null) videoPlayer.playOnAwake = false;
    }

    public void ShowExhibit(ExhibitInfo info)
    {
        if (panelRoot != null) panelRoot.SetActive(true);
        if (titleText != null)       titleText.text = info != null ? info.title : "";
        if (descriptionText != null) descriptionText.text = info != null ? info.description : "";
        if (imageView != null)
        {
            imageView.sprite = info != null ? info.image : null;
            imageView.enabled = imageView.sprite != null;
        }
        ConfigureVideo(info);
        PlaySelectionAudio(info);
    }

    public void HidePanel()
    {
        StopVideo();
        if (panelRoot != null) panelRoot.SetActive(false);
    }

    private void ConfigureVideo(ExhibitInfo info)
    {
        if (videoPlayer == null) { if (videoView != null) videoView.enabled = false; return; }
        StopVideo();
        videoPlayer.clip = info != null ? info.video : null;
        bool hasVideo = videoPlayer.clip != null;
        if (videoView != null) videoView.enabled = hasVideo;
        if (hasVideo) videoPlayer.Play();
    }

    private void StopVideo()
    {
        if (videoPlayer == null) return;
        if (videoPlayer.isPlaying) videoPlayer.Stop();
    }

    private void PlaySelectionAudio(ExhibitInfo info)
    {
        if (audioSource == null) return;
        AudioClip clip = (info != null && info.selectionAudio != null)
            ? info.selectionAudio : defaultSelectionAudio;
        if (clip != null) audioSource.PlayOneShot(clip);
    }
}
```

## 六、场景搭建步骤（逐字段对照 Inspector）

### Step 1 — 准备 XR Origin
场景里放 PICO 的 **XR Origin (VR)**（包含 PXR_Manager、Main Camera）。

### Step 2 — 建 GazeManager 空物体，挂两个脚本
1. `XREyeGazeInputSource`：
   - **Fallback Camera** → 拖 Main Camera（留空会自动取 `Camera.main`）
   - **Simulate In Editor** → ✅（编辑器用鼠标调试）
   - **Use Mouse Point In Editor** → ✅
   - **Xr Origin Transform** → **拖 XR Origin (VR) 最外层物体**（关键！）
2. `GazeSelectionController`：
   - **Gaze Input Source Behaviour** → 拖上面的 `XREyeGazeInputSource` 组件
   - **Max Ray Distance** → 30
   - **Dwell Duration** → 1.5（停留秒数，按需调）
   - **Interactable Layer Mask** → 选展品所在 Layer（或 Everything）
   - **Gaze Progress Image** → 拖准星圆环（见 Step 4）
   - **Info Panel Controller** → 拖面板控制器（见 Step 5）

### Step 3 — 每个展品挂 GazeInteractable
- 该物体（或子物体）必须有 **Collider**（射线要打中它）。
- **Interaction Type**：展品选 `OpenExhibit`，关闭按钮选 `CloseInfoPanel`
- **Exhibit Info**：填标题/描述/图片/视频/音效
- **Scale Target**：要放大的 Transform（留空=自身）
- **Highlight Renderers**：拖该物体的 MeshRenderer（可多个）
- **Normal Color / Focus Color**：常态色 / 高亮色

### Step 4 — 准星进度环（可选但推荐）
屏幕中心放一个 UGUI **Image**，**Image Type = Filled**（Radial 360）。拖给 controller 的 **Gaze Progress Image**。注视时圆环按 0→1 填充，满了即触发。

### Step 5 — 信息面板
建一个面板根物体（World Space Canvas 推荐，VR 里跟随视野），挂 `ExhibitionInfoPanelController`：
- **Panel Root** → 面板根（启动会自动 SetActive(false)）
- **Title Text / Description Text** → TMP 文本
- **Image View** → 展示图 Image
- **Video View / Video Player** → RawImage + VideoPlayer（无视频可留空）
- **Audio Source / Default Selection Audio** → 选中音效

## 九、常见坑速查

| 现象 | 原因 / 排查 |
|---|---|
| 真机完全没反应 | PXR_ProjectSetting 的 Eye Tracking 没勾；或设备不支持眼动 |
| 射线方向/位置错位 | `xrOriginTransform` 没拖对，或方向误用了 MultiplyPoint |
| 高亮不变色 | 材质属性名不是 `_BaseColor`/`_Color`（自定义 Shader 改 `BaseColorId`） |
| 注视打不中物体 | 物体没 Collider；或被 LayerMask 过滤掉 |
| 编辑器无法 Play/报 PXR 错 | 真机调用没用 `#if !UNITY_EDITOR` 包裹 |
| 面板里视频不播 | VideoPlayer 没拖、或 clip 为空（代码会自动隐藏 videoView） |
| 数据偶尔无效 | 用 `vectorWorld.sqrMagnitude > 0.001f` 过滤；进阶可查 `GetCombinedEyePoseStatus` |
